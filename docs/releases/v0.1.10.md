## SpinSlicer v0.1.10 — стабильная версия без симулятора

В этой версии три вкладки: **Слайсер**, **Проектор (Видео)** и **Настройки**.
Экспериментальная симуляция и библиотека подбора смол в этот релиз не входят.

- Загрузка STL, изменение размера, положения и поворота модели.
- Генерация проекций, передача кадров в проектор, просмотр и экспорт MP4.
- Настройки принтера и процесса, опциональный движок VAMToolbox.
- Исправлена упаковка Qt, библиотек Visual C++ и VTK для Windows.
- Сборка исключает инструменты проверки типов, которые могли мешать запуску PyVista.

Перед выпуском выполняются тесты и проверка собранных приложений:
запуск трёх вкладок, генерация восьми кадров, проверка манифеста,
передача кадров в проектор и экспорт читаемого MP4.

Для Windows скачайте **SpinSlicer-Setup-0.1.10.exe** для установки или
**SpinSlicer.exe** для запуска без установки. Для Linux доступны архив, DEB и RPM.
Приложение готовит проекции и видео; управление реальным принтером не включено.
